# DataStructure_2025Fall

复旦大学 2025 年秋季《数据结构》（CS20009.04）的实验、项目、笔记和复习材料。授课教师为[郑晓晴](https://faculty.fudan.edu.cn/zhengxq/zh_CN/index/155051/list/index.htm)。课程说明见 `2025202601-CS20009.04-数据结构.pdf`。教材是《算法导论》。本仓库不收录教材 PDF。

实验和项目代码是个人作业。课件、笔记扫描件和历年试题的版权归教师与学校。
